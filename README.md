# Leitstelle 112 (Arbeitstitel)

Realistischer Leitstellensimulator für den deutschen Rettungsdienst, Brandschutz und
Katastrophenschutz – lokal und offline unter Windows 10/11.

Stand: **Phase 0 (Planung)**. Es gibt noch keinen lauffähigen Code.

- Plan: [docs/PLAN.md](docs/PLAN.md)
- Architekturentscheidungen: [docs/adr/](docs/adr/README.md)
- Konventionen: [CLAUDE.md](CLAUDE.md)
- Änderungen: [CHANGELOG.md](CHANGELOG.md)
- Lizenzen: [docs/LICENSES.md](docs/LICENSES.md)

Hinweis: Dies ist ein Spiel. Es ist kein Schulungswerkzeug mit fachlicher Verbindlichkeit für
den realen Leitstellen- oder Rettungsdienstbetrieb.
