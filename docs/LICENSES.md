# Lizenzen und Quellen

Jede fremde Komponente, Schrift, Grafik und jeder Datensatz wird hier eingetragen, **bevor**
er ins Repository kommt. Eigene Werke sind als „Eigenwerk" vermerkt.

Status: Phase 0 – noch keine Abhängigkeiten installiert. Die Einträge unter „Geplant"
werden beim Einbau geprüft (exakte Version und Lizenztext) und nach „Verwendet" verschoben.

## Projektlizenz

- Quellcode: GPL-3.0-or-later (`LICENSE`)
- Eigene Inhalte, Grafiken, Texte, Regionspakete: CC BY-SA 4.0 (`content/LICENSE.md`)
- Begründung: ADR-0013. Alle Abhängigkeiten müssen GPL-3.0-kompatibel sein.
